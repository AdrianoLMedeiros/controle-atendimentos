# Controle de Atendimentos SPA

## Objetivo

Criar um SPA simples para registrar, listar, filtrar e acompanhar atendimentos administrativos.

## Stack

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia

## Escopo inicial

A versão 0.1 deve conter:

- Estrutura base do projeto
- Layout principal
- Rotas principais
- Página inicial
- Página de listagem de atendimentos
- Página de novo atendimento

## Fora do escopo inicial

- Backend
- Autenticação
- Banco de dados
- Upload de arquivos
- Relatórios avançados
- Controle de permissões

## Diretrizes

- Código simples
- Componentes pequenos
- TypeScript sempre que aplicável
- Sem bibliotecas externas sem aprovação
- Persistência local apenas em etapa posterior
